# rt64: rt64_math.cpp keeps the game's decomposition of a view-projection (least squares over the three rows, its
# 0001), which mends what the web's (the row where the view's Z axis is largest) mends, one way. rt64_gbi.cpp has the
# web's L3DEX2.fifo 2.06 and the game's Acclaim L3DEX2 (its 0002), which the web leaves Unknown. The extended GBI's
# flags (state.h, workload.h and .cpp) are both: the game's framebufferAspect and the web's pipelineWarmUp. In
# rt64_projection_processor.cpp the game's exactViewProj goes before the web's interpolated camera eye. In
# rt64_shader_library.cpp the game's BloomCS (its 0006) is in the web's WGSL list too, and made with the web's
# CREATE_SHADER_INPUTS, which takes the shader's name.
# N64ModernRuntime: in audio.cpp the web's check of a sound buffer's address comes first, then the game's count of the
# bytes deterministic mode (netplay, its 0004) plays. In mesgqueue.cpp the game's message source for deterministic
# mode's order and the web's held blocked messages are both kept: deterministic mode returns before the web's paths.
# threadqueue.cpp walks the queue the game's way (it clears the thread's queue too) after the web's check of a null
# queue.
# N64Recomp: analysis.cpp is the game's, whose 0001 finds a jump table in another section, as the web's change to it
# (its only one) does for GoldenEye.
