# The RT64 shaders the web page builds: one shader description a line, other mode L and H, color combiner L and H,
# flags, in hex. RT64 specializes each one's WGSL when the page is built and builds them with the game waiting: those
# above the first "section" line before the game starts, and a section when a frame first wants 4 of its shaders, so
# that nothing draws with the ubershader, which integrated graphics can't afford (N64Recomp-browser's README, "Give
# RT64 a list of the game's shaders").
#
# Recorded by playing, a page load a section: N64Recomp-browser's tools/record_shaders.mjs with
# tools/shader_plan.json, which drives the menus with PaxDino's keys (Enter selects, the arrow keys move, W is C-Up)
# and knows where the game is by the game's mode and the front end's screen (tools/game_state.js), in the Modern
# preset. Section 0 is the launcher, the boot screens, the title and the menus to level select: Multiplayer, one
# player, the first character, the default loadout. Then a Bloodlust match, one bot, on each of the nine maps a new
# save offers, reached by Down at level select, its options and Rumble Pak screens on the way, and played 45 s of the
# match's clock as tools/play_plan.json plays (walking out and back, turning, firing), with the pause list once: Grim
# Retreat, Fallout, Bomb Shelter, Fire Temple, The Pit, Leap of Faith, Crypts, Hopeless and Proving Grounds. Not
# recorded: the maps a save unlocks later, the team, Frag Tag and flag modes' maps, 1 Player Trials, split screen and
# a match's end. Flags follow settings (filtering, the screen filters, bloom), so a change to one of those defaults
# means recording again. The last three of section 0 were missed in a match by tools/play_plan.json's plays in Chrome
# (one at 1256x645, two more at 3840x2000) and are put where they are built before the game starts.
